# rule-07-handoff-and-artifacts

## handoff-discipline
- keep handoffs in a dedicated folder (docs/handoffs).
- each milestone must have a markdown summary handoff.
- automated "super bundle" output is preferred for external review.

## no-bloat
- do not duplicate the full super-bundle inside docs.
- docs should link to the latest bundle filename if needed.
